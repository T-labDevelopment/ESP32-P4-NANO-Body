# ESP32-P4-NANO筐体 Rev.C — 2026-10-22

**現行の試作候補。実物の嵌合は未検証。Rev.Bは端子開口位置の取り違えにより試作不良となったため、そのまま履歴として残す。**

## 実機写真で確認した事実

IMG_4592.jpeg（会話内ユーザー提供写真）では、筐体の天面を上にした端子側正面から見ると、**左側にUSB-A、右側にRJ45**が見える。旧Rev.Bの共通開口の左側が大きく空き、RJ45右側の余裕が小さい。基板を回転・反転させるのではなく、外装の開口位置を修正する。

## CAD変更

- 旧Rev.B前面開口のCAD X範囲: **-21.4 ～ +13.4 mm**（幅34.8mm）。
- 新Rev.C前面開口のCAD X範囲: **-23.0 ～ +1.8 mm**（幅24.8mm）。
- +Y側をUSB-A/RJ45の共通開口とし、**天面を上にして外側から見るとUSB-Aが左、RJ45が右**の向きと定義。
- 装着方向は固定し、基板支持部・底蓋・四隅4点ネジ固定はRev.Bから変更しない。
- USB-C（-Y側）の開口も現状維持。ユーザー写真ではUSB-C側は確認できないため実寸未検証。
- 外形**74×62×31.5mm**、一般側壁2.0mm、端子面1.8mm、天面2.8mm、底蓋3.2mm、内蔵ネジ柱Ø10.6mm×4。PETG/Bambu Lab A1想定。

**注意:** 位置・端子幅は写真からの概算であり、メーカー提供3Dコネクタモデルによる完全検証ではない。組立STEPには目視検査用の推定端子直方体を含む。実機未検証のまま製造完成品として扱わないこと。

## まず前面嵌合確認用モデルを印刷する

**推奨：完成筐体の再印刷よりも先に端子面のみ試し刷りする。**

- `ESP32_P4_NANO_RevC_front_coupon_upper.stl`：上ケースのUSB-A/RJ45側、奥行き19mmだけを切り出した模型。
- `ESP32_P4_NANO_RevC_front_coupon_bottom.stl`：上記と対になる基板支持・位置決め用の試作底蓋。
- 基板の前側2箇所の穴と試作蓋を合わせ、**USB-Aが左・RJ45が右**か、コネクタハウジングが当たらないか、USB-Aが最後まで差さるか、RJ45のツメが操作できるかを確認する。
- 試作カットモデルは完成品として使わず、動作中は四隅4点でネジ止めする。
- USB-C側はRev.B現物の通りを検査し、不具合があれば本体を再印刷する前にCAD寸法を確定させる。

## CAD再生成

Rev.Bの機械CADを再利用するため、`../rev-b/generate_enclosure.py` は削除しない。

```sh
python -m pip install -r rev-c/requirements.txt
python rev-c/generate_enclosure.py
```

生成品: `rev-c/ESP32_P4_NANO_RevC_upper_print.stl`、`...bottom_print.stl`、`...front_coupon_upper.stl`、`...front_coupon_bottom.stl`、上下個別STEP、組立STEPなど。

CAD上では上下・基板外形の体積干渉0。STL4個とも閉じた単一メッシュを確認。ただし実際のコネクタ嵌合・配線・温度・ねじ締付強度は未確認。
