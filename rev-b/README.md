# ESP32-P4-NANO 筐体 Rev.B / 2026-10-22

Waveshare ESP32-P4-NANO 標準基板用、Bambu Lab A1 / PETG想定。
**実機での嵌合・ケーブル抜き差し・温度試験は未実施。試作用CADであり製造確認済みではない。**

## Rev.Aから変更した内容
- 四隅の外部ねじ耳を廃止し、**74 × 62 × 31.5 mm** の角丸長方形に内包する。
- 筐体は空洞とし、肉厚補強は主に内側のM3ねじ固定柱（Ø10.6 mm、4箇所）に限定する。
- 通常側壁2.0mm、USB-CとRJ45/USB-Aのある2面は**1.8mm**、天面2.8mm、底蓋3.2mm。
- RJ45＋USB-Aは共通開口、USB-Cは反対面に独立開口。底面からM3低頭ねじ4本で固定。
- 4つのPCB穴周辺を上下の小型パッドで挟み、底蓋側のØ1.65mmの位置決めピンを使用。
- 基板50×50mm、穴中心ピッチ45.1mm（メーカー寸法図参照）。取付方向は端子面をY正負側に向ける。

外装をコネクタより外へ張り出させ、横からの衝撃を受けにくくした設計。ただし**ポート前面までの実際の奥まり量およびプラグ可動域は未測定**。RJ45ラッチ操作性とUSB-Cプラグの樹脂部が干渉しないことを必ず確認する。

## STL・STEP生成

    pip install cadquery==2.8.0
    python generate_enclosure.py

生成物: ESP32_P4_NANO_RevB_upper_print.stl（天面を下に造形）、ESP32_P4_NANO_RevB_bottom_print.stl（底面側を下に造形）、ESP32_P4_NANO_RevB_assembly.step（本体＋底蓋＋基板輪郭プロキシ）、上下個別STEP。

PETG、積層0.2mm、外周3〜4周を初期値に。インサートM3（外径約4.6mm・長さ約5mm）、M3×8低頭ねじ各4個を想定し、実際のねじ頭高さ、推奨下穴径を確認する。

## 組立確認
1. ねじ柱4箇所にM3熱圧入インサートを取り付ける。
2. USB-A/RJ45を大きい共通開口側に向けてPCBを内部の支柱に置く。
3. 底蓋の四つの小径ピンを穴に合わせ、対角順に軽く締める。PCBを曲げない。
4. USB-A、USB-C、RJ45プラグの挿抜、ラッチの取り外し操作、カバーのたわみを評価。
5. 運転時の温度・Wi-Fi通信状態を実測する。

CadQueryによるモデル検査で、筐体/蓋/簡易PCB外形の体積重複0、STL2枚は閉じた一体メッシュ。印刷・現物装着は未実施。基板穴内径、基板厚、各端子の高さ・突出、PoEの増設可否は未検証で、PoEアドオン等は非対象。
